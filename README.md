# Portfolio Website

A modern personal portfolio website built with Next.js, React, Tailwind CSS, and WebGL-powered visuals.

## Overview

This repository contains the source code for a portfolio website featuring animated sections, responsive layout, and 3D-enhanced UI elements.

## Features

- Responsive portfolio layout
- Hero section with animated text and background effects
- Modular components for projects, skills, and contact information
- Three.js and `@react-three/fiber` powered visuals
- Optimized for local development and production builds

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- Tailwind CSS 4
- Three.js
- `@react-three/fiber`
- `@react-three/drei`
- `cobe`
- `maath`
- `motion`

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for Production

```bash
npm run build
npm start
```

## Available Scripts

- `npm run dev` — start the Next.js development server
- `npm run build` — build the app for production
- `npm run start` — start the production server
- `npm run lint` — run ESLint checks

## Project Structure

- `app/` — application routes, layout, and UI components
- `app/components/` — reusable UI components
- `app/sections/` — page sections like Hero, About, and Navbar
- `public/` — static assets, images, and icons
- `models/` — 3D scene or data model files
